#تحديث واجهة إدارة مشواري — لوحة الكمبيوتر

## محتويات التحديث
- `public/admin.html`: واجهة إدارة جديدة بتصميم مكتبي احترافي، قائمة جانبية على اليمين، محتوى يتغير عند اختيار القسم، ونافذة جانبية قابلة للفتح على الهاتف.

## طريقة الاستبدال
1. افتح مستودع Meshwari في GitHub.
2. افتح المجلد `public`.
3. استبدل الملف `admin.html` بهذا الملف الموجود داخل الحزمة.
4. احفظ التغيير في الفرع `main` وانتظر نشر Render.

**مهم:** هذا التحديث يغيّر `public/admin.html` فقط. لا تستبدل `server.js` أو ملفات التطبيق الأخرى بهذا التحديث. الواجهة تستعمل واجهات API الحالية للحسابات والمركبات والرحلات والسياسات والتدقيق والمديرين المفوضين وWhatsApp OTP.

## ملاحظات التحقق
- تم فحص صياغة JavaScript المضمنة باستخدام `node --check`.
- تم فحص صياغة `server.js` الموجود في التحديث السابق باستخدام `node --check` دون تعديله.
- الإحصائيات تقرأ من `/api/admin/overview`، والجداول من نقاط API الحالية.
- مساحة الخريطة لا تعرض مواقع وهمية؛ تظهر رسالة انتظار إلى أن تتوفر بيانات مواقع مباشرة.
- لم يتم تنفيذ نشر على GitHub أو Render من هذه الحزمة، ولم يتم اختبار اتصال WhatsApp/Meta الفعلي.
