تحديث التسجيل الإلزامي بالصور - مشواري
التاريخ: 15 نوفمبر 2026

محتويات الحزمة:
- server.js
- public/index.html
- public/admin.html

ما يضيفه التحديث:
1) الراكب: صورة البطاقة الشخصية الأمامية والخلفية إلزاميتان.
2) السائق: صورة البطاقة الأمامية والخلفية، ووثائق السيارة (من صورة إلى 3 صور)، وصورة سيلفي، وصورة السيارة نفسها؛ جميعها إلزامية.
3) يضغط المتصفح الصور إلى JPEG قبل الرفع لتقليل الحجم. الحد الأقصى للصورة الواحدة 2 ميغابايت، وإجمالي الملفات 12 ميغابايت.
4) يحفظ الخادم الصور في جدول PostgreSQL جديد mesh_registration_documents، مشفرة باستخدام AES-256-GCM بمفتاح مشتق من JWT_SECRET.
5) الصور لا تظهر إلا للمدير المصادق عليه من لوحة الإدارة > الحسابات > عرض الصور والمستندات.
6) يمنع الخادم اعتماد حساب راكب أو سائق جديد ما لم تكتمل مستنداته المطلوبة.
7) عند الحذف النهائي/تجهيل الحساب، تُحذف صور الهوية والسيلفي ووثائق السيارة وصورة السيارة.

طريقة التحديث:
1) خذ نسخة احتياطية من قاعدة PostgreSQL وملفات GitHub الحالية.
2) استبدل server.js في جذر المستودع.
3) استبدل public/index.html و public/admin.html داخل مجلد public.
4) لا تغيّر package.json ولا متغيرات Render. يجب إبقاء JWT_SECRET الحالي كما هو؛ لا تغيّره لأن مفتاح تشفير الصور مشتق منه، وتغييره يمنع فك تشفير الصور المحفوظة سابقاً.
5) ارفع الملفات إلى فرع main وانتظر نجاح Render.
6) افتح التطبيق بعد النشر. جرّب تسجيل راكب تجريبي بصور أمام/خلف، ثم راجع الصور من لوحة الإدارة.
7) جرّب تسجيل سائق تجريبي مع كل الصور المطلوبة، ثم راجعها من لوحة الإدارة.

ملاحظات مهمة:
- عند أول تشغيل، ينشئ الخادم جدول الصور والفهرس تلقائياً عبر initDb؛ لا حاجة إلى SQL يدوي.
- صور المستندات مشفرة في قاعدة البيانات، ولا يوجد رابط عام مباشر لها. عرض الصور يتطلب صلاحية المدير.
- لا تُرسل صور هوية حقيقية للاختبار. استخدم صوراً تجريبية أولاً.
- تم فحص صياغة server.js وJavaScript المضمن في صفحتي الراكب/السائق والإدارة باستخدام node --check.
- لم يتم اختبار ترحيل PostgreSQL أو رفع الصور على Render الحي؛ يلزم اختبار ذلك بعد النشر.
- التحديث لا يغير الأيقونات أو إعدادات المركبات أو بقية واجهات الرحلات والدفع.
