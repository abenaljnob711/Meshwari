مشواري — تحديث المديرين المفوضين وواتساب OTP

محتويات التحديث:
1) server.js — إضافة حسابات مديرين مفوضين وصلاحيات منفصلة، مع الإبقاء على جدول وحساب المدير الرئيسي الحالي دون حذف أو إعادة إنشاء.
2) public/admin.html — إضافة شاشة إدارة المديرين والصلاحيات، وإعدادات واتساب، وشاشة إصدار رموز التفعيل للمدير المفوض.

الملفات التي لم تتغير:
- public/index.html
- package.json
- render.yaml
- معرّفات تطبيقي مشواري.

قبل تفعيل واتساب:
أضف المتغيرات التالية في Render Environment Variables، ولا تضع الأسرار في ملفات المشروع:
- WHATSAPP_ENABLED=false (يبقى false حتى تجهز الربط الرسمي وتختبره)
- WHATSAPP_PHONE_NUMBER_ID=معرف رقم الهاتف من Meta WhatsApp Cloud API
- WHATSAPP_ACCESS_TOKEN=رمز وصول خادم Meta
- WHATSAPP_API_VERSION=إصدار Graph API مدعوم بصيغة vNN.N

بعد ربط Meta واعتماد قالب OTP:
- افتح لوحة الإدارة > واتساب OTP.
- أدخل اسم القالب المعتمد ولغته.
- غيّر WHATSAPP_ENABLED إلى true في Render بعد التأكد من إعداد بيانات Meta.
- فعّل الإرسال من لوحة الإدارة.

القالب المستخدم في هذا الإصدار يجب أن يقبل متغير نص واحد في نص الرسالة (body) لرمز OTP. لا تُفعّل الإرسال قبل اعتماد القالب والتحقق من بنيته في Meta.

السلوك الأمني:
- يبقى الإرسال التلقائي متوقفاً افتراضياً.
- إذا كان واتساب متوقفاً أو فشل الإرسال، يعرض الخادم الرمز فقط للمدير الذي يملك صلاحية إصدار OTP حتى يتم تسليمه يدوياً.
- عند إصدار رمز جديد تُبطل الرموز السابقة غير المستخدمة.
- الرمز صالح 5 دقائق ويستخدم مرة واحدة.
- لا يسجل الخادم رمز OTP أو مفاتيح واتساب في سجلاته.
- تعطيل المدير المفوض أو تغيير صلاحياته يبطل جلساته الحالية.
- صلاحيات المدير المفوض محدودة بالخدمات التي يمنحها المدير الرئيسي؛ باقي عمليات الإدارة تبقى للمدير الرئيسي فقط.

ملاحظة: هذا تحديث ملفات فقط؛ لم يتم نشره إلى GitHub أو Render ولم يتم اختبار اتصال Meta الفعلي، لأن بيانات Meta غير متوفرة بعد. اختبارات الصياغة البرمجية (node --check) نجحت.
